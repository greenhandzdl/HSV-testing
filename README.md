# 颜色比色挑战（HSL / HSV Color Match）

纯静态比色小游戏：随机给一个目标色，用 **色相 H / 饱和度 S / 明度 L** 三个滑块还原，每题 **3 次猜测**，成绩存 `localStorage`，可分享链接、生成 1080×1350 分享卡片（本题卡 + 历史战绩卡）。无后端、无构建、无第三方依赖。线上 Demo：<https://hsl-test.greenhandzdl.moe>。

出题、评分、URL 参数全用 **HSL**；**HSV 只作换算展示**（出现在悬停浮层与卡片里，不参与打分）。

## 本地运行

模块脚本受 CORS 限制，`file://` 打不开，用 `python3 tools/serve.py`（默认端口 8000）。它把 listen backlog 放大（标准库 `http.server` 只有 5，十几个模块并发拉会随机 RST），并带文件监听：改 CSS 只热换样式不丢页面状态，改 JS / HTML 才整页刷新。推 `main` → Pages 选 `main` + `/ (root)` 即发布；资源全走相对路径，子路径同样可用。

## 结构

- `index.html` 唯一页面；`src/css/` 六个样式域按 `tokens → shell → layout → game → history → responsive` 顺序 `<link>`（响应式必须最后，才能盖住前面的规则）。
- `src/js/` 17 个 ES 模块，`main.js` 是唯一入口，其余模块彼此不认识。两张分享卡共用 `card.js` 画图工具箱（版式预算 / 逐题条 / 二维码 / 导出），`card-round.js`、`card-history.js` 各画一张，数据由 `game.js` 打包送进来。零依赖二维码编码器 `src/js/qr.js` 可用 `node tools/qr-check.mjs` 对拍 ISO/IEC 18004。

## 玩法与评分

- 三条滑杆轨道都带真实色带；猜测提交后凝固成圆点，**悬停 / 点击即可回看它的 HSL 与 HSV**。
- **目标色**结算前只有颜色，读数 / 浮层 / `aria-label` 一并封死防作弊。选项「显示目标数值」默认关，「自动递增」按 ≥88 升级 / <45 降级。
- 难度 1–10 有两个入口（页眉 ± 步进器、比色台下拉，都走同一个 `setDifficulty`）：步进器 ±1 不弹确认，下拉可跳多级、放弃未结算尝试前会确认。
- 评分：`dH = min(|ΔH|, 360−|ΔH|)`，`total = 100 × (0.65·(1−dH/180) + 0.20·(1−|ΔS|/100) + 0.15·(1−|ΔL|/100))`，最终分取三次最高。难度只把饱和度高斯均值压到 `clamp(85−6d, 15, 85)`（越高越灰）。
- 窄屏（≤760px）把「两组色块 + 三个滑杆 + 提交」压进同一屏，DOM 顺序不变，桌面端零影响。

## 分享

- **链接**：`?h=&s=&l=&d=` 分享题目；`?share=result|history&data=<base64url>` 打开只读视图，不读写访问者 localStorage。逐题最多 8 条，超 1800 字符退化为「摘要 + 最佳色」。
- **卡片**：都是 1080×1350 PNG（4:5）。手机上优先 `navigator.share` 交给系统分享面板，**只有系统不支持文件分享时才降级下载**，任一情况下都只产出一张图；二维码载荷超 150 字符则退回首页；目标色未结算时卡上不露数值。
  - **本题卡**（比色台下方）：本题得分 + 评价、目标色 / 我的最佳双块、三次猜测圆点、最近几题成绩条，二维码指向这一题。
  - **历史卡**（历史面板下方）：均分大数字为主角，逐题条最多 10 行，样本数与面板逐字对齐；二维码只带汇总数字（`?share=h`），落地是只读摘要页。

## 改版提醒

改了 CSS 或入口 `main.js` **必须递增** `index.html` 里的 `?v=`（6 条 CSS + 入口共 7 处一起改），否则浏览器磁盘缓存会继续端出旧构建。可调参数集中在 `src/js/config.js` 的 `CONFIG`（整棵 frozen）。
