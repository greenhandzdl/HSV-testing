# 颜色比色挑战（HSL / HSV Color Match）

纯静态比色小游戏：随机生成目标色，用 **色相 H / 饱和度 S / 明度 L** 三个滑块还原，每题 **3 次猜测**，成绩存 `localStorage`，可生成分享链接与 1080×1350 分享卡片（本题卡 + 历史战绩卡）。无后端、无构建、无依赖；线上 Demo：<https://hsl-test.greenhandzdl.moe>（主页页脚也有仓库友链）。出题、评分、URL 参数全用 **HSL**，**HSV 只作换算展示**（`V = L + S·min(L,1−L)`，`S_hsv = 2·S·min(L,1−L)/V`），出现在悬停浮层与卡片里，不参与打分。

## 目录与本地运行

`index.html` + `src/css/`（六个样式域：`tokens` `shell` `layout` `game` `history` `responsive`，按这个顺序 `<link>`，响应式必须排最后）+ `src/js/`（17 个 ES 模块，`main.js` 是唯一入口）+ `tools/`。两张分享卡共用 `card.js` 这套画图工具箱（版式预算 / 逐题条 / 二维码 / 导出），`card-round.js` 与 `card-history.js` 各画一张，数据由 `game.js` 打包送进来。模块脚本受 CORS 限制，`file://` 打不开，本地跑 `python3 tools/serve.py 8000`（默认端口就是 8000；标准库 `http.server` 的 backlog 只有 5，十来个模块并发拉会随机 RST；它带文件监听，改 CSS 只热换样式不丢页面状态，改 JS / HTML 才整页刷）。想换 `npx serve` 也行，但要认清是 npm 那个 14.x、不是 Homebrew 装的 Go 版 `serve`：它只发 `ETag` 不发 `Cache-Control`，改完文件普通刷新照样拿到新内容，代价是没有热重载（每次手刷），且默认 `cleanUrls` 会让 `/index.html?share=…` 连吃两道 301 把 query 丢光——改用 `/?share=…`，或 `-c` 挂一份仓库外的 `{"cleanUrls": false}`。推 `main` → Pages 选 `main` + `/ (root)` 即发布（`greenhandzdl.github.io/HSV-testing/` 会 301 到上面的自定义域名），资源全走相对路径，子路径同样可用。零依赖二维码编码器 `src/js/qr.js` 可用 `node tools/qr-check.mjs` 对拍 ISO/IEC 18004 结构与容量表（约 3000 项断言）。

## 玩法

- 三条轨道都带真实色带：色相固定彩虹，饱和度 / 明度随当前取值变；轨道下方有端点刻度。
- 猜测提交完就凝固成圆点，**悬停 / 点击即可回看它的 HSL 与 HSV**——猜测色不是答案，不必等结算；圆点下方写死的得分与 ★ 最佳标记才在结算后出现。
- **目标色**结算前只有颜色：读数、浮层、`aria-label` 一并封死防作弊。「显示目标数值」默认关闭，「自动递增」按 ≥88 升级 / <45 降级。
- 难度有两个入口（页眉 ± 步进器与比色台下拉，都走同一个 `setDifficulty`）：步进器只 ±1 且不弹确认，下拉能一次跳多级、放弃未结算尝试前会确认。
- 窄屏（≤760px）把「两组色块 + 三个滑杆 + 提交」压进同一屏：色块保持两列，`.stage` 用 `display:contents` 让三个孩子直接进面板的 flex 列并靠 `order` 重排，难度行与选项退到本轮记录之后；矮屏（≤700px 高）再折掉页眉副标题、收紧色块高度。DOM 顺序一个字没动，所以桌面端零影响；首屏预算按「色块底 / 三根滑杆底 / 提交底 均 ≤ 视口高」算，改完窄屏样式至少拿 320×568 与 360×640 两台量一遍。

## 评分与难度

`dH = min(|ΔH|, 360−|ΔH|)`，`total = 100 × (0.65·(1−dH/180) + 0.20·(1−|ΔS|/100) + 0.15·(1−|ΔL|/100))`，最终分取三次最高。难度 1–10 只把饱和度高斯均值压到 `clamp(85−6d, 15, 85)`（越高越灰），色相 0–359、明度 25–80 均匀分布。

## 历史与分享

- 面板列最近 5 / 8 / 10 题：题号、难度、准确率、评价，外加目标方块与三次圆点（每点下方标该次得分，最佳那次双环 + ★）。按难度分桶写 `hsvColorMatch.history.v1`，切难度不丢数据，汇总指标实时派生。
- `?h=&s=&l=&d=` 分享题目；`?share=result|history&data=<base64url>` 打开只读视图，不读写访问者 localStorage。逐题最多 8 条，超 1800 字符退化为「摘要 + 最佳色」。
- 分享卡片都是 1080×1350 PNG（4:5，小红书 / 朋友圈直发）：手机上优先 `navigator.share`，不支持就下载；二维码载荷超 150 字符则退回首页；目标色未结算时卡上也不露数值。
  - **本题卡**（比色台下方）：本题得分 + 评价文案、目标色 / 我的最佳双块、三次猜测圆点，加最近几题成绩条；二维码指向这一题。
  - **历史卡**（历史面板下方）：均分大数字是主角，配评价句与 最高/最低/σ/样本数 一行，下面逐题条最多 10 行（目标色方块 + 三次猜测圆点），行数跟着面板的「最近 N」走，卡上样本数与面板逐字对齐；二维码只带六个汇总数字（`?share=h`），落地是只读摘要页，不带逐题记录也不读写访问者的 localStorage。

## 改版提醒

`index.html` 里的 `?v=10` 是手动版本号，六个 `?v=` 一起改；改完 CSS / 入口 **必须递增**，否则浏览器磁盘缓存会继续端出旧构建（`src/js/` 内部的 import 不带版本号，改子模块请硬刷或 Disable cache）。可调参数集中在 `src/js/config.js` 的 `CONFIG`。
